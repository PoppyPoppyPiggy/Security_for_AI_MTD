A security information and event management (SIEM) system collects and analyzes log data from across an organization's technology infrastructure. SIEMs provide real-time analysis of security alerts generated by applications and network hardware. They use correlation rules and machine learning to identify patterns that may indicate a security incident. Modern SIEM platforms integrate with threat intelligence feeds to enhance detection capabilities.

Public key infrastructure (PKI) is a framework for managing digital certificates and public-key encryption. It enables secure electronic communication through certificate authorities (CAs) that issue and verify digital certificates. PKI underpins technologies such as TLS/SSL for secure web browsing, email encryption, and code signing. Certificate lifecycle management including issuance, renewal, and revocation is critical for maintaining trust in PKI systems.

Network segmentation divides a computer network into smaller subnetworks to improve security and performance. By isolating sensitive systems and data into separate segments, organizations can limit the lateral movement of attackers who breach the perimeter. Micro-segmentation extends this concept to individual workloads using software-defined policies. Effective segmentation is a key component of defense-in-depth strategies.

Encryption is the process of converting plaintext data into an unreadable format called ciphertext using a cryptographic algorithm and a key. Only authorized parties who possess the correct decryption key can convert the ciphertext back to readable plaintext. Common encryption standards include AES-256 for symmetric encryption and RSA for asymmetric encryption. Encryption is essential for protecting data both at rest and in transit.

Data loss prevention (DLP) is a set of tools and processes used to ensure that sensitive data is not lost, misused, or accessed by unauthorized users. DLP solutions monitor and control data in three states: at rest (stored data), in motion (network traffic), and in use (endpoint activity). They use content inspection and contextual analysis to identify sensitive information such as personally identifiable information, financial records, and intellectual property.

Penetration testing is an authorized simulated cyberattack performed to evaluate the security of a system. Penetration testers use the same tools and techniques as malicious attackers to identify vulnerabilities that could be exploited. Testing methodologies include black-box (no prior knowledge), white-box (full system knowledge), and gray-box (partial knowledge) approaches. Results are documented in detailed reports with remediation recommendations prioritized by risk.

Multi-factor authentication (MFA) requires users to provide two or more verification factors to gain access to a resource. These factors typically include something you know (password), something you have (security token), and something you are (biometric). MFA significantly reduces the risk of unauthorized access even if one factor is compromised. Organizations increasingly mandate MFA for accessing sensitive systems and data.

Vulnerability scanning is the process of systematically identifying security weaknesses in computer systems, networks, and applications. Automated scanners compare system configurations and software versions against databases of known vulnerabilities such as the CVE database. Regular scanning is a fundamental component of any security program and is often required for regulatory compliance. Scan results are typically prioritized by severity using the CVSS scoring system.

A virtual private network (VPN) creates an encrypted tunnel between a user's device and a remote server, masking the user's IP address and encrypting all data in transit. VPNs are commonly used by remote workers to securely access corporate networks. They prevent eavesdropping on public Wi-Fi networks and can bypass geographic content restrictions. Enterprise VPN solutions often integrate with identity management systems for access control.

Security orchestration, automation, and response (SOAR) platforms combine three capabilities to streamline security operations. Orchestration connects and coordinates multiple security tools and systems. Automation handles repetitive tasks such as enriching alerts with threat intelligence. Response provides structured workflows called playbooks for consistent incident handling. SOAR platforms help security teams manage increasing alert volumes while reducing mean time to respond.

Malware is malicious software designed to damage, disrupt, or gain unauthorized access to computer systems. Common types include viruses that attach to legitimate programs, worms that self-replicate across networks, trojans that disguise themselves as legitimate software, and ransomware that encrypts files and demands payment for decryption. Anti-malware solutions use signature-based detection, behavioral analysis, and machine learning to identify and neutralize threats.

Cloud security encompasses the policies, technologies, and controls deployed to protect data, applications, and infrastructure in cloud computing environments. The shared responsibility model defines that cloud providers secure the infrastructure while customers are responsible for securing their data and configurations. Key cloud security concerns include identity and access management, data encryption, network security, and compliance monitoring across multi-cloud environments.

Access control is a security technique that restricts who or what can view or use resources in a computing environment. Role-based access control (RBAC) assigns permissions based on organizational roles rather than individual users. The principle of least privilege dictates that users should only have the minimum permissions necessary to perform their job functions. Proper access control is critical for protecting sensitive data and maintaining regulatory compliance.

A firewall is a network security device that monitors and filters incoming and outgoing network traffic based on predefined security rules. Firewalls establish a barrier between trusted internal networks and untrusted external networks such as the internet. They can be hardware-based, software-based, or a combination of both. Modern firewalls also perform deep packet inspection to detect malicious payloads.
